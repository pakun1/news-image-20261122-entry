- **DISASTER** — Rescuers search for 36 people missing after a candy factory

  two-day state visit.
- **TRADE** — The EU and Indonesia seal a landmark trade pact after a decade
  of talks.

## How it works

`main.py` copies the pre-rendered front page, `entry.png`, into the output
directory as `entry.png`. The image is produced deterministically, so every
run writes the same bytes. It uses only the Python standard library and
needs no network access.
